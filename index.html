开始使用

获取 Skill 后，在 Codex 中打开你的课题项目，告诉 Codex Skill 文件的位置并请它安装。安装完成后，在新一轮对话中使用 $tte-workflow。可以从临床问题、已有研究方案或已整理的分析数据开始。

可复制的起始提示词

使用 $tte-workflow。我想在【目标人群】中比较【策略 A】与【策略 B】，评估【结局】在【随访时限】内的差异。我有【数据字典、表结构或队列文件】。先拟定目标试验方案，并核实这些数据能否确定入组资格、共同起点、治疗记录、关键混杂因素和结局。数据支持时，按方案完成分析、诊断和报告。

只做选题、方案审阅或结果复核时，直接注明当前阶段即可。需要运行示例或正式分析时，按取得的 Skill 包内说明配置 R 和所需依赖。取数工具由数据格式与课题环境决定。

从研究问题到效应估计

  1. 选题与查新

    明确一项临床决策，查阅相关试验、指南和观察性研究，说明本次比较会补充什么证据。

  2. 写出目标试验

    定义人群、资格、干预和对照、策略分配、随访、结局及估计目标。在共同的 time zero 对齐资格判断、策略分配和随访开始。

  3. 核查数据可行性

    研究者根据可取得的数据和随访情况决定数据来源。用数据字典和病例时间线核实字段含义、可用时点、治疗与结局的先后，以及每种策略是否有足够的观测支持。

  4. 按方案分析

    根据策略和估计目标选择方法。预先规定宽限期、策略偏离、失访与竞争事件的处理。纵向协变量采用决策时已可获得的信息，推断考虑同一患者的克隆或重复入组。

  5. 核对诊断与解释

    按方法检查组间重叠、协变量平衡、权重分布、删失和有效样本量。报告效应大小、区间、关键假设和敏感性分析。

如果无法定位共同起点、确定治疗策略或观测关键混杂与结局，应先说明缺口。由研究者决定补充资料或修订研究问题，再继续估计。

按研究问题选择方法

研究情形可考虑的实现
在起点比较两种选择视估计目标和数据条件，采用倾向评分加权、标准化、AIPW 或基线 TMLE。
允许在窗口内启动明确宽限期和策略兼容性后考虑克隆–删失–加权（CCW）。处理人工删失及由此产生的选择问题。
治疗决策反复出现可用序贯目标试验定义每轮的资格、分配和随访，并在推断中纳入患者内相关。
比较持续或动态策略先核实各决策时点的治疗历史与时变混杂，再判断纵向 g-formula、LTMLE 或其他纵向方法是否适用。

因果解释取决于所用数据、模型和识别假设，包括一致性、可交换性及正值性。实际研究需检查时间顺序、随访和策略支持，再解释结果。

结果与报告

从方案到结果应能逐项追溯。保存目标试验与数据实现对照表、队列流程、变量来源与处理规则、分析代码、未舍入效应值及诊断。按估计目标呈现风险、风险差或其他适用指标及其区间，并解释主要限制与敏感性分析。可用 TARGET 指南检查报告透明度。

常见问题

我还没有最终选题，可以先用吗？

可以。提供疾病、临床决策场景和大致数据条件，先做查新和可行性评估，确定哪些问题值得进入正式方案。

已经有清洗好的队列表，怎么开始？

提供字段字典、研究起点、治疗定义及随访规则，请 Codex 核对数据与目标试验方案的对应关系。需要纵向分析时，再核查每个决策时点的观测历史。

出院后看不到死亡，还能分析固定期限全因死亡吗？

先核实出院后结局覆盖和观察终止，并说明相应假设。院内死亡是另一项结局，是否调整研究目标应由研究者根据临床问题决定。
